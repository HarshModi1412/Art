# Scene backdrop library: prompts

Generate each image **once**, in any image tool, and save it into `backend/static/scenes/` with **exactly** the file name shown (`.jpg`, `.png` or `.webp` all work). After that, every scene picture the app makes is free.

**Settings for every image:** vertical **9:16**, the highest resolution your tool offers (1080 x 1920 or more). Photorealistic.

**Check before saving:** the empty spot (podium top, table centre, palm, neckline, earlobe, hook) must really be empty. If the tool put a bottle or a necklace there, generate again. People's faces should be out of frame where the prompt says so.
